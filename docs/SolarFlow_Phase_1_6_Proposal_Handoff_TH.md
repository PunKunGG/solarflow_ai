## 1. แนวคิดโครงการในประโยคเดียว

SolarFlow AI เป็นแนวคิดพัฒนาชั้นปรับสภาพเชิงแสงแบบ retrofit สำหรับติดตั้งบน
กระจกด้านหน้าของแผงโซลาร์เซลล์เดิม เพื่อเพิ่มสัดส่วนแสงที่ส่งผ่านเข้าสู่เซลล์
โดยไม่ต้องเปลี่ยนหรือซื้อแผงใหม่ทั้งชุด

แนวคิดนี้สนับสนุน Circular Innovation ในมิติของการเพิ่มคุณค่าการใช้งานให้
สินทรัพย์เดิม แต่ยังไม่มีข้อมูลเพียงพอสำหรับคำนวณผลประโยชน์ด้านวัฏจักรชีวิต
ต้นทุน คาร์บอน หรือพลังงานตลอดอายุใช้งาน

---

## 2. ปัญหาและโอกาส

ฟาร์มโซลาร์เซลล์ที่ติดตั้งแล้วมีต้นทุนการเปลี่ยนหรือเพิ่มแผงสูง แนวทางของ
SolarFlow AI จึงตั้งคำถามว่า:

> สามารถเพิ่มการรับแสงของแผงเดิมด้วยชั้นวัสดุเชิงแสงที่บางมาก โดยไม่เปลี่ยน
> ตัวแผงหลักได้หรือไม่?

ตัวอย่างบริบทของโครงการคือฟาร์มโซลาร์เซลล์ลอยน้ำเขื่อนสิรินธร ซึ่งทำให้
ประเด็นความชื้น น้ำ ฝน การยึดเกาะ การทำความสะอาด และความทนทานมีความสำคัญ
เทียบเท่ากับประสิทธิภาพเชิงแสง

## 3. สถาปัตยกรรมที่ใช้เป็นจุดอ้างอิง

โมเดล Phase 1.6 ใช้โครงสร้างแบบ direct coating ดังนี้:

```text
อากาศ
-> ชั้น active optical layer: n = 1.092934, k = 0, d = 116.736 nm
-> ชั้น release primer: n = 1.20, d = 50 nm
-> ชั้น AR เดิมที่สมมติ: n = 1.28, d = 100 nm
-> กระจกหน้าแผงตัวแทน: n = 1.52
```

ความหมายของแต่ละชั้น:

- **Active optical layer:** ชั้นดัชนีหักเหต่ำสำหรับลดการสะท้อนและปรับการส่งผ่านแสง
- **Release primer:** ชั้นเชื่อมต่อที่ตั้งใจให้รองรับการติดตั้งหรือการถอดออกในอนาคต
- **Existing AR:** ชั้นลดการสะท้อนเดิมของแผง ซึ่งค่าจริงของรุ่นเป้าหมายยังไม่ทราบ
- **Cover glass:** กระจกหน้าแผงที่ใช้ค่าดัชนีหักเหตัวแทนในแบบจำลอง

ค่าดัชนีและความหนาของ active layer เป็นผล optimization ไม่ใช่สูตรวัสดุหรือ
ข้อกำหนดการผลิตจริง ส่วน release primer ยังไม่มีการเลือกวัสดุเชิงพาณิชย์

แบบจำลองปัจจุบัน **ไม่มี protective topcoat** เนื่องจากชั้นป้องกันที่นำมา
screen ก่อนหน้านี้ทำให้ optical margin หายไป การออกแบบการป้องกันผิวยังเป็น
งานวิจัยที่ต้องทำใหม่

## 4. เครื่องมือและวิธีวิจัย

| เครื่องมือ | หน้าที่ในโครงการ |
|---|---|
| Meep | ตรวจสอบแบบจำลองคลื่นแม่เหล็กไฟฟ้าและ numerical convergence |
| Transfer-Matrix Method | คำนวณการสะท้อนและส่งผ่านของโครงสร้างชั้นบาง |
| Solcore | ให้สเปกตรัม AM1.5G และสนับสนุนการถ่วงน้ำหนักเชิงแสง |
| Optuna | ค้นหาค่าดัชนีหักเหและความหนาที่เหมาะสมภายใต้แบบจำลอง |
| DuraMAT/NREL/Sandia SR data | ให้ spectral-response proxy ที่วัดจากโมดูลเชิงพาณิชย์ |

ขั้นตอนหลัก:

```text
สร้าง baseline ของแผงเดิมแบบย่อ
-> optimize active layer และ primer
-> ตรวจ convergence และ tolerance
-> กวาด uncertainty grid 20,160 กรณี
-> ถ่วงน้ำหนักด้วย measured SR proxy 3 รุ่น
-> รายงานผลพร้อมข้อจำกัดและ research gates
```

AI ใช้ช่วยจัดการ workflow วิเคราะห์ผล และพัฒนาโค้ดที่ทำซ้ำได้ แต่ตัวเลข
สุดท้ายมาจากแบบจำลองที่กำหนดสมการ พารามิเตอร์ และข้อมูลอ้างอิงไว้อย่างชัดเจน
ไม่ใช่การให้ AI คาดเดาประสิทธิภาพของแผง

## 5. ผล Phase 1.6A — Optical uncertainty

Phase 1.6A ทดสอบสมมติฐานด้าน optical stack จำนวน `20,160` กรณี

| ตัวชี้วัด | ผล |
|---|---:|
| Nominal relative optical gain | `+0.6667%` |
| ค่าต่ำสุดของ grid | `-0.7657%` |
| ค่ามัธยฐาน | `+0.6315%` |
| กรณีที่มี gain เป็นบวก | `18,234 / 20,160 (90.45%)` |
| กรณีที่ผ่าน provisional margin `+0.10%` | `17,430 / 20,160 (86.46%)` |

ตัวแปรที่มีผลต่อความไม่แน่นอนมากที่สุด:

1. ดัชนีหักเหของ AR เดิม
2. ความหนาของ AR เดิม
3. ค่า extinction coefficient ของ active layer

ข้อสรุปคือ nominal design ให้ผลบวก แต่ยังไม่ robust ครบทุกสมมติฐาน และควร
ให้ความสำคัญกับการวัด optical stack จริงมากกว่าการปรับ optimizer ต่อโดยไม่มี
ข้อมูลใหม่

## 6. ผล Phase 1.6B — Measured SR proxy ensemble

Phase 1.6B ใช้ normalized spectral response ที่ได้จากการวัดโมดูล mono-Si
PERC เชิงพาณิชย์ 3 รุ่น ได้แก่ Itek, QCells และ Mission Solar

```text
20,160 optical cases × 3 SR proxies = 60,480 combinations
```

ผล nominal:

| SR proxy | Relative photocurrent-proxy gain |
|---|---:|
| Itek | `+0.8139%` |
| QCells | `+0.8152%` |
| Mission Solar | `+0.8144%` |
| Minimum / median / maximum | `+0.8139% / +0.8144% / +0.8152%` |

ผล conservative grid:

| ตัวชี้วัด | ผล |
|---|---:|
| กรณีที่เป็นบวกในทุก proxy | `17,719 / 20,160 (87.89%)` |
| กรณีที่ผ่าน `+0.10%` ในทุก proxy | `16,948 / 20,160 (84.07%)` |
| Worst across-proxy case | `-1.0089%` |

ผล nominal ของทั้งสาม proxy ต่างกันเพียงประมาณ `0.0013` percentage points
จึงสรุปได้ว่า ภายใน proxy ensemble ที่เลือก รูปร่าง SR ไม่ใช่แหล่งความไม่แน่นอน
หลักของ nominal result ความไม่แน่นอนที่สำคัญกว่ายังคงเป็น optical stack จริง
และสมบัติของวัสดุ

## 7. วิธีตีความตัวเลข `+0.814%`

ตัวเลขประมาณ `+0.814%` หมายถึง:

> ผลต่างสัมพัทธ์ของ normalized photocurrent proxy หลังนำ modeled spectral
> transmission modifier ไปถ่วงด้วย measured normalized SR ของโมดูลอ้างอิง

ตัวเลขนี้ **ไม่ใช่**:

- กำลังไฟฟ้าที่เพิ่มขึ้นจริงของ JAM72D10-405/MB
- ผลผลิตพลังงานที่เพิ่มขึ้นจริงของโรงไฟฟ้าเขื่อนสิรินธร
- ค่าที่วัดจากแผงหลังติดตั้งวัสดุ
- การรับรองประสิทธิภาพ ความทนทาน หรือความปลอดภัย
- ความน่าจะเป็น 84.07% หรือ 87.89% ที่ผลิตภัณฑ์จะสำเร็จ

สาเหตุที่ยังแปลงเป็น electrical power gain ไม่ได้คือยังไม่มี EQE/SR ของแผง
เป้าหมายแบบเจาะจง ไม่มี baseline/retrofit I–V ที่วัดภายใต้เงื่อนไขเดียวกัน และ
SR proxy ที่ใช้ถูก normalize จึงไม่ให้ค่า absolute A/W หรือกระแสจริง

## 8. ข้อความที่ใช้ใน Proposal ได้

### เวอร์ชันทางการ

> ภายใต้สมมติฐานของโครงสร้างเชิงแสงที่กำหนด แบบจำลอง SolarFlow AI ให้ค่า
> nominal relative optical-transmission gain ประมาณ 0.667% และเมื่อถ่วง
> modeled spectral modifier ด้วย normalized spectral response ที่วัดจากโมดูล
> mono-Si PERC เชิงพาณิชย์สามรุ่น ให้ nominal relative photocurrent-proxy gain
> ประมาณ 0.814% โดยผลจากทั้งสาม proxy ใกล้เคียงกัน อย่างไรก็ตาม uncertainty
> grid ยังมีกรณีที่ผลเป็นลบ และ proxy ดังกล่าวไม่ใช่ข้อมูลของ
> JAM72D10-405/MB โดยตรง ผลนี้จึงเป็นหลักฐานเชิงตัวเลขเบื้องต้น ไม่ใช่ผลเพิ่ม
> กำลังไฟฟ้าหรือพลังงานที่ยืนยันจากแผงจริง

### เวอร์ชันสั้นสำหรับสไลด์

> ผลจำลอง nominal ยังคงเป็นบวกเมื่อทดสอบด้วย measured SR proxy สามชุด แต่
> ยังต้องตรวจยืนยัน optical stack, EQE/SR, I–V และวัสดุจริงก่อนกล่าวอ้าง
> electrical gain

### เวอร์ชันพูดประมาณ 30 วินาที

> เราไม่ได้เริ่มจากการอ้างว่าวัสดุเพิ่มไฟได้ทันที แต่เริ่มจากจำลองว่าถ้าเพิ่ม
> ชั้นดัชนีหักเหต่ำบนกระจกเดิม แสงจะส่งผ่านเข้าสู่เซลล์ได้มากขึ้นหรือไม่
> ผล nominal ทางแสงอยู่ที่ประมาณ 0.667% และเมื่อถ่วงด้วยข้อมูล spectral
> response ที่วัดจากโมดูลอ้างอิงสามรุ่น ผล photocurrent proxy อยู่ประมาณ
> 0.814% อย่างไรก็ตามยังมีบางสมมติฐานที่ให้ผลติดลบ เราจึงนำเสนอเป็นหลักฐาน
> เบื้องต้นและกำหนดแผนทดสอบจริงไว้ชัดเจน

## 10. โมเดลแนวคิด 1 ชิ้นที่ควรออกแบบต่อ

### รูปแบบที่แนะนำ

สร้าง **โมเดลตัดขวางแบบ exploded layer** ของมุมแผงโซลาร์เซลล์ เพื่อให้เห็น
ลำดับชั้นดังนี้:

```text
แสงอาทิตย์
↓
Active optical layer
↓
Release primer
↓
Factory AR — assumed / measurement required
↓
Cover glass
↓
Solar cell
```

องค์ประกอบที่ควรมี:

- โมเดลแผงขนาดย่อส่วนหรือเฉพาะมุมแผง
- แผ่นใสแยกชั้นสำหรับอธิบาย active layer, primer, AR และ glass
- ลูกศรแสดงแสงตกกระทบ แสงสะท้อน และแสงที่ส่งผ่าน
- ป้าย `Conceptual model — not to scale`
- สีแยกชั้นชัดเจน แต่ active layer ต้องดูบางที่สุด
- ช่องเปรียบเทียบ `Existing panel` กับ `SolarFlow retrofit concept`
- QR code เชื่อมไปยัง GitHub หรือรายงาน Phase 1.6

โมเดลนี้เป็น **สื่ออธิบายแนวคิด** ไม่ใช่ prototype ที่สร้างพลังงานเพิ่มจริง
การใช้แผ่นอะคริลิกหรือพลาสติกในโมเดลมีไว้แสดงชั้นเท่านั้น ไม่ได้หมายความว่า
ผลิตภัณฑ์จริงจะใช้ carrier film เพราะชั้น carrier สามารถเปลี่ยนผลทางแสงได้

## 13. แผนการตรวจยืนยันจริง

### ข้อมูลจากแผงเป้าหมาย

- spectral responsivity หรือ EQE ของโมดูลจริง
- reflectance/transmittance ของกระจกและ AR เดิม
- baseline I–V ภายใต้ irradiance และ temperature ที่ควบคุม
- ข้อมูล optical stack หรือผล ellipsometry หากเข้าถึงได้

### ข้อมูลจากวัสดุ candidate

- `n(lambda)` และ `k(lambda)`
- ความหนาและความสม่ำเสมอ
- haze และ surface roughness
- optical response ในสภาวะแห้งและเปียก
- adhesion, abrasion, removability และ accelerated aging

### การเปรียบเทียบขั้นต้น

```text
แผงหรือ coupon เดียวกัน
-> วัด baseline
-> ติดตั้ง candidate ด้วยกระบวนการที่บันทึกได้
-> วัดซ้ำภายใต้เงื่อนไขเดียวกัน
-> รายงาน uncertainty และ repeatability
```
