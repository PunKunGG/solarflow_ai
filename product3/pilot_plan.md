# Product 3 — Solar Integration Pilot

## Phase A: Cell-level A/B
1 control cell
1 treatment cell
Same illumination/temperature conditions.

## Phase B: Module-level A/B
1 control module
1 treatment module
Instrument both modules identically.

## Phase C: Pilot array
Expand only if Phase B shows statistically defensible improvement without unacceptable side effects.

## Metrics
- Pmax
- Voc
- Isc
- efficiency
- kWh/day
- kWh/kWp
- temperature coefficient
- optical response
- degradation / stability

## Pilot logic
The EGAT challenge expects prototype, POC and pilot planning, including Desirability, Viability and Feasibility. The pilot should therefore quantify technical benefit, economic value, maintainability and environmental impact.
